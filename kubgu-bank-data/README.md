# Синтетический банковский портфель для кейса КубГУ

Источник данных — модель учебного портфеля, сгенерированная детерминированно. Все остатки, ставки и курсы синтетические. Внешние данные при генерации не использовались.

Основной файл `bank_portfolio.xlsx` содержит **756 записей и 10 полей** на листе `positions`. Первая строка содержит заголовки, следующие строки — данные. В наборе 54 позиции на каждый из 14 срезов. Двенадцать срезов сделаны на конец месяца с ноября 2025 по октябрь 2026 года, два дополнительных — на 12 и 13 октября 2026 года.

## Карточка данных

Одна запись — совокупный остаток по виду позиции, продукту, валюте и диапазону оставшегося срока на дату среза. Эти пять полей (`as_of_date, side, product, currency, maturity_bucket`) образуют составной ключ. Портфель охватывает восемь продуктов в рублях, долларах США и евро. Это выборка позиций для анализа, поэтому суммы активов и пассивов могут различаться.

| Поле | Тип | Значение |
| --- | --- | --- |
| `as_of_date` | Дата Excel | Дата среза |
| `snapshot_kind` | Текст | `MONTH_END` — на конец месяца, `DAILY` — дополнительный дневной срез |
| `side` | Текст | `ASSET` — активы, `LIABILITY` — пассивы |
| `product` | Текст | Банковский продукт, например ипотека или корпоративные депозиты |
| `currency` | Текст | Валюта позиции, `RUB`, `USD` или `EUR` |
| `maturity_bucket` | Текст | Диапазон оставшегося срока до погашения на дату среза |
| `balance_ccy` | Число | Остаток в единицах валюты позиции, точность до сотых |
| `fx_rub_per_unit` | Число | Синтетический курс в рублях за единицу валюты. Для RUB равен 1 |
| `balance_rub` | Число | Рублёвый эквивалент позиции, `ROUND(balance_ccy * fx_rub_per_unit, 2)` |
| `rate_annual` | Число | Годовая ставка в долях единицы. Например, `0.125` соответствует 12,5% |

## Загрузка и проверка

Запустите из папки с файлами. Загрузчик читает XLSX и выводит JSON с путём источника, именем листа, числом записей, заголовками, типами по столбцам и примерами проблем с номерами строк Excel. Код возврата 0 означает успешную проверку, код 1 — ошибку чтения или валидации.

```powershell
python -m pip install openpyxl==3.1.5
python profile_xlsx.py bank_portfolio.xlsx
python profile_xlsx.py bank_portfolio_invalid.xlsx
```

В тестовом файле ячейка `I3` содержит текст вместо суммы, `J4` пуста, строка 758 повторяет строку 2 и её ключ. Проверки бизнес-правил включают допустимые коды, диапазон ставок, знак остатка, единство курса на дату по валюте и пересчёт в рубли.

## Метрики и контрольные значения

- **Динамика активов.** Суммируйте `balance_rub` по дате с фильтрами `side = 'ASSET'` и `snapshot_kind = 'MONTH_END'`. Ожидаемые значения на 30.11.2025 и 31.10.2026 — **954 885 038,03 ₽** и **1 022 303 980,96 ₽** соответственно.
- **Рублёвые позиции.** Добавьте к предыдущему запросу фильтр `currency = 'RUB'`. Для тех же дат ожидаются **858 544 508,12 ₽** и **911 801 579,57 ₽**.
- **Влияние курса USD на пассивы.** Сравните 12 и 13.10.2026 с фильтрами `side = 'LIABILITY'` и `currency = 'USD'`. Курс вырос с **96,35** до **97,10 ₽ за USD**. Курсовой эффект при фиксированном вчерашнем остатке в USD (`B₁₂ × (FX₁₃ − FX₁₂)`) составил **+589 329,15 ₽**. Эффект изменения остатка по курсу 13 октября составил **+43 996,98 ₽**. По сумме округлённых строк пассивы в USD выросли на **633 326,14 ₽**. Разница в одну копейку связана с округлением каждой позиции.
- **Структура пассивов.** На выбранную дату доля продукта равна сумме его `balance_rub`, делённой на сумму `balance_rub` всех пассивов в выбранном фильтре. Средневзвешенная ставка равна `SUM(rate_annual * balance_rub) / SUM(balance_rub)`. Для обеих метрик нужен ненулевой знаменатель.

Остатки суммируются по позициям на одну дату. Для месячной динамики используйте только `MONTH_END`, чтобы дневные срезы не попали в итог месяца. Для агрегации разных валют используйте рублёвый эквивалент.
